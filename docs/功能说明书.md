# NEEPU CTF 平台功能说明书

> 版本：基于仓库 `main` 分支梳理  
> 技术栈：Vue 3 + Vite 前端 / Flask + Gunicorn 后端 / MySQL + Redis / Docker 容器题  
> 说明：本文将每个用户可见功能细化到**源文件 + 函数/方法**；标注 **410** 的路由为已下线兼容路径。

---

## 一、项目架构

```
选手浏览器
    ↓
frontend/src/router/index.js          路由与权限守卫
frontend/src/components/*.vue         页面与交互
frontend/src/services/*.js            API 封装
    ↓ HTTP /api/*
backend/app.py                        Flask 应用入口、蓝图注册
backend/route/*.py                    REST API 路由处理
backend/services/*.py                 业务逻辑服务层
backend/server/*.py                   配置、ORM、邮件、容器访问、审计
    ↓
MySQL (db_models) / Redis / Docker Engine
```

## 五、使用说明

### 5.1 环境准备

1. 复制 `backend/.env.example` → `backend/.env`，填写数据库、JWT、邮件等（**勿提交 `.env`**）。
2. MySQL 建库后启动后端，`create_app()` 会自动 `db.create_all()` 建表。
3. 创建管理员：`python backend/scripts/create_admin.py`（需设置 `NEPU_ADMIN_PASSWORD`）。
4. 前端：`cd frontend && npm install && npm run dev`（默认 `http://localhost:5173`）。
5. 后端：Flask 开发或 Gunicorn 生产部署（见 `docs/deploy-single-server.md`）。

### 5.2 选手使用流程

```
1. 打开落地页 /  → 点击「为世界上所有美好而战」或进入 /auth
2. 注册 /account/register → 查收邮件 → /verify-email 完成验证
3. 登录 → 进入 /home 工作台
4. 浏览赛事 /contests → 点击赛事 → /games/:id 查看详情
5. 加入赛事（公开赛直接加入；非公开需邀请码）
6. 若无战队：/games/:id/teams 创建或加入
7. 进入题目 /games/:id/challenges → 左侧选题，右侧做题
8. 附件题：下载附件；容器题：点击「启动容器」→ 复制 connection_url 访问
9. 在 Flag 输入框提交 → 正确则计分并显示一血信息
10. 查看排行 /games/:id/scoreboard
```

**训练场：** 访问 `/training`，无需正式报名，调用 `training-join` 后进入 `ChallengeWorkspace`（`mode=training`）。

### 5.3 管理员使用流程

```
1. 使用管理员账号登录
2. 进入 /admin/ctf → 创建赛事（设置开始/结束时间、类型、是否公开）
3. 在同一页管理题目：创建题目、配置 flag/flag_template、Docker 镜像与端口
4. 动态容器题：配置 docker_image、docker_port、flag_template（如 NEEPUCTF{{{team_hash}}}）
5. 部署时设置 NEPU_CONTAINER_PUBLIC_HOST 为公网 IP/域名
6. 非公开赛：创建分组与邀请码，分发给选手
7. 赛中：/admin/ctf 查看排行榜、作弊记录、流量包
8. 赛后：归档赛事或导出 CSV 积分榜
9. 平台配置：/admin/settings（注册开关、验证码、维护模式等）
```

### 5.5 运维与排错

| 现象 | 排查位置 |
|------|----------|
| 注册失败 503 | `maintenance_service.is_exempt_path()`；检查维护模式 |
| 提示比赛未开始 | `time_utils.game_has_started()`；检查 `CtfGame.start_time/status` |
| Flag 总是错 | `flag_generator.resolve_challenge_expected_flag()`；检查模板与 `team_hash_salt` |
| 容器地址不对 | `container_access.normalize_connection_url()`；检查 `NEPU_CONTAINER_PUBLIC_HOST` |
| 容器启不动 | `container_service.create_container()` 日志；Docker 是否可用、端口是否耗尽 |
| 提交 429 | `submit_lock.redis_submit_lock()`；Redis 限流或提交过快 |
