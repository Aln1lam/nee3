# Awesome Design（NEEPU）

**主规范：`docs/ui-style.md`**（与 `ui-style-guide.md` 同步）

**视觉锚点：`frontend/src/components/Home.vue`**

- 100vh 单屏 + 248px 通底 Sidebar + 版权底栏
- 双栏 `1.3fr : 1fr`（`golden-dual-column`）
- Token：`var(--primary)` / `var(--accent)` / `var(--card-bg)` / `var(--page-bg)`
