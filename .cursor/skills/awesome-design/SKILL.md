# Awesome Design Skills（NEEPU 项目）

## 何时使用

- 设计或改版 `frontend/` 页面、主题、Landing、组件
- 用户提到设计感、配色、二次元、动漫风、去 AI 味

## 本项目默认风格

**主 Skill：`neepu-anime-ui`**（二次元 / 轻游戏 UI + Anthropic 设计流程 + 布局约定）

| Token | 深色参考 | 说明 |
|-------|----------|------|
| primary | `#5ED9A8` / `#2DB58A` | 薄荷绿主色 |
| accent | `#F472B6` / `#EC4899` | 樱花粉 chip |
| depth | `#7EB8FF` / `#60A5FA` | 渐变辅色 |
| canvas | `#1A1D2E` / `#F0FBF6` | 深/浅底 |

相关文件：
- `.cursor/skills/neepu-anime-ui/SKILL.md` — **必读**
- `.cursor/skills/neepu-anime-ui/LAYOUT.md` — 侧栏布局
- `frontend/public/themes/dark.css` / `light.css`
- `frontend/src/assets/collapsible-sidebar.css`

> `matrix` / `neon` 已降级为历史参考，新 UI 勿用黑客终端方向。

## 已安装 Skill
